# Instructions du projet

## Principes de travail

- Travaille uniquement sur le périmètre explicitement demandé.
- Inspecte seulement les fichiers nécessaires à la tâche.
- N’effectue pas d’audit général du dépôt sans demande explicite.
- Ne consulte pas le web ou de la documentation externe sauf blocage réel.
- N’ajoute aucune dépendance sans nécessité démontrable.
- Réutilise l’architecture et les composants existants.
- Ne refactore pas de code sans rapport direct avec la tâche.
- Pour une modification simple, ne produis pas de plan détaillé.
- Exécute d’abord les tests ciblés, puis une seule vérification globale si nécessaire.
- Ne répète pas plusieurs fois les mêmes commandes ou vérifications.
- Ne committe, ne pousse et ne déploie rien sans demande explicite.
- Reste concis dans les explications et le compte rendu final.
